# Проект Foodgram

## Краткое описание:
Проект YaCut — это сервис укорачивания ссылок. Его назначение — ассоциировать длинную пользовательскую ссылку с короткой, которую предлагает сам пользователь или предоставляет сервис.

Дополнительная функция YaCut — загрузка сразу нескольких файлов на Яндекс Диск и предоставление коротких ссылок пользователю для скачивания этих файлов.

## Настройка вашего .env:
Для корректной работы проекта создайте .env в корневой директории проекта и используйте следующие константы:

**DATABASE_URI** = 'sqlite:///db.sqlite3'
**DISK_TOKEN**=<ваш токен> (токен можно взять в документации к API Яндекса, либо любого другого, с которым планируете работать)
**SECRET_KEY**=<ваш секретный ключ> (ключ необходим для WTForms, его вы придумываете самостоятельно)
**FLASK_APP**=<название директории приложения или дефолтный для нашего случая yacut>

## Подключение БД:
При помощи SQLAlchemy подключите SQLite, используя команду "sqlite:///C:\<ваша директория, в которой лежит папка с проектом>\<имя папки проекта>\db.sqlite3".

## Установка и запуск:
1. Разверните (python -m venv venv) и активируйте (sourse venv/Scripts/activate) виртуальное окружение.
2. Установите зависимости из requirements.txt при помощи "pip install -r requirements.txt".
3. Создайте миграции с помощью "flask db migrate", а также не забудьте сохранить изменения при помощи "flask db upgrade".
4. Запустите сервер при помощи "flask run" (для этого не забудьте внести в .env константу FLASK_APP)
